# 🎬 OZON IPTV

**Your Entertainment. One Subscription.**

OZON IPTV is a modern, responsive website designed to showcase streaming subscription plans and provide customers with an easy way to contact the service through WhatsApp.

## ✨ Features

- 🎨 Professional dark blue, black, and yellow design.
- 📱 Fully responsive layout for mobile, tablet, and desktop.
- 🏷️ Subscription pricing cards.
- 🖼️ Six-image gallery with replaceable image placeholders.
- 💬 WhatsApp contact integration.
- 🎯 Modern navigation and landing page.
- ⚡ Lightweight frontend built with HTML, CSS, and JavaScript.

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Replace the placeholder images with your own licensed images.
5. Customize the content and contact information.
